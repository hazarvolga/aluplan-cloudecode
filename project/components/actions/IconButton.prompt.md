Square icon-only button with a required accessible label (menu toggle, dialog close).

```jsx
<IconButton icon="x" label="Kapat" />
<IconButton icon="menu" label="Menüyü aç" variant="on-brand" aria-expanded={false} />
```

md size = --target-min (44px aluplan / 40px field). sm is for dense toolbars only and stays ≥ 32px.
