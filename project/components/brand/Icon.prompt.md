Lucide-sourced line icon (copied geometry, never hand-drawn). Decorative unless `label` is given.

```jsx
<Icon name="file-text" />
<Icon name="circle-alert" label="Hata" />
```

Stroke width comes from `--icon-stroke` (2 in aluplan, 1.5 in field). Add icons by copying from lucide-static into assets/icons/lucide and regenerating Icon.jsx.
